ABOUT MOTION CHALLENGE

Fair, reproducible motion evaluation.

An open-source benchmark that uses a unified evaluation core, public code and configurations for fair, reproducible model comparisons.

What we are building

A collection of benchmarks with one reusable core and independent model adapters. LAFAN40 on G1 29DoF is the first dataset. We publish the evaluation code and distinguish maintainer reproductions from author submissions.

Every metric follows the same rules within its benchmark, robot and protocol. The evaluation code is public, checkpoint and source revisions are pinned, and results have reproduction commands and per-motion evidence. Author-specific observations, control frequency and action processing are documented separately. Results are tied to checkpoint and protocol versions. Corrections should remain visible, with previous versions retained. Questions about an adaptation or score belong in the public issue tracker.

Acknowledgments

We thank the authors of the released controllers, LAFAN1 and the LAFAN1 retargeting dataset, MuJoCo and mjlab. Model names identify upstream work, not endorsement of this benchmark.

The site's organization was informed by the separation of protocol, aggregate results and task detail in RoboTwin, the benchmark and documentation structure of RoboCasa, the public evaluation presentation of RoboChallenge, and MimicLite's project documentation. This project is independent of those teams.

Current limitations

The current track uses privileged simulator state and nominal canonical physics. Inference reviews and independent adapter reruns are in progress. Benchmark scores do not establish real-world performance or generalization beyond this dataset.
