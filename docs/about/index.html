ABOUT MOTIONCHALLENGE

Motion tracking, openly evaluated.

An open, reproducible benchmark for humanoid motion tracking.

MotionChallenge

Public checkpoints, shared evaluation rules and independently verified results. Each model has a reproducible adapter with pinned source, weights and dependencies. LAFAN40 is our first dataset.

Model cards describe the released inference path and any benchmark adaptation. Detailed results include per-motion scores, the exact evaluated code and verification records.
