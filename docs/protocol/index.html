EVALUATION PROTOCOL

Evaluation protocol

A versioned protocol separates model inference from the conditions under which it is measured.

Evaluation contractAlignment metricsAuthor inferenceEvidence & limits

01 · A fixed evaluation contract

The shared core uses official mujoco.batch with MuJoCo 3.17.0. Every model keeps its native policy clock and independent history; PD is recomputed every physics step. Download and evaluation progress is emitted every five seconds. Only MuJoCo 3.17.0 batch is supported by the public evaluation entrypoint.

The core controls source data, interpolation, robot asset, physics, reset state, clocks, termination and scoring. The adapter controls observations, native history/recurrent state, network inference and action processing.

LAFAN40 starts from the first reference pose and velocity. Every clip runs to its exact last timestamp, including after the first tracking failure, without resetting. Reference queries outside the clip are clamped without shortening the episode. No evaluation noise or randomization; friction is 1.

Failure conditions

  • Absolute torso height error exceeds 0.25 m.
  • Reference-versus-actual projected-gravity Z difference exceeds 0.8.
  • Maximum wrist or ankle world-height error exceeds 0.25 m.

See LAFAN40 failure conditions for formulas, exact bodies and endpoint behavior. No additional XY or tracking-precision threshold is introduced. The complete suite and one checkpoint are required. A smoke truncation or infrastructure failure cannot be counted as a passed motion.

02 · Three views of tracking error

XY + yaw alignment

Remove per-frame horizontal root translation and relative world-Z heading before measuring 14 keybody positions. Retain height and tilt. This describes local body tracking with horizontal trajectory and heading factored out.

XY alignment

Remove only per-frame root XY translation. Retain heading, height and tilt, so a heading mismatch remains visible.

No alignment

Compare world-frame body positions directly. Global translation and heading drift remain in the result.

MPBPE means mean per-body position error: Euclidean distances across 14 named body origins, reported in millimetres. The legacy JSON keys are named mpjpe_*_m; these measure body positions, not joint angles. Joint MAE is separately measured in radians.

The XY + yaw transform uses the closest relative world-Z rotation derived from both pelvis orientations. Samples with ambiguous heading are retained and reported. See the implementation for the exact formula.

Coverage is part of the interpretation

One complete rollout produces six metric views: three alignment methods over the prefix through the first failure, and the same three over the entire motion. For each view, first average frames within a motion, then equally across motions. Success and completion retain the same first-failure definition. Both time ranges are computed from the same complete trajectory, without resetting after failure.

03 · Follow the author's inference

Pin the source and checkpoint. Check observations, joint order, coordinate frames, control frequency, reference lookahead, normalization, history initialization, recurrent memory, action scales, clipping, gains and filters. Compare input tensors, raw network outputs and final motor targets on identical sequences, including reset and endpoint cases.

Document benchmark-specific differences. A shared robot and physics protocol can differ from an author's training environment; matching inference does not reproduce their paper scores. Checkpoint conversion requires a numerical equivalence test.

04 · Reproducible results

  1. Artifact provenance: fixed checkpoint, source revision and dependency lock.
  2. Inference parity: tested against author-maintained inference.
  3. Complete evaluation: every clip under one protocol and checkpoint.
  4. Trace verification: independently recompute failures and metrics.

Each result links its evaluation code, checkpoint, configuration and independently recomputed trajectory metrics. The shared core applies the same benchmark conditions to every model.
