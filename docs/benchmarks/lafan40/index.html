SUCCESS & FAILURE

When does a motion end?

A clip passes only when it reaches the exact final reference timestamp without a failure. All 40 clips use the same checkpoint, and each starts from the first reference pose and velocity.

ConditionCompared at the same timestampFailure threshold
Torso heightAbsolute world-Z difference between actual and reference torso_link> 0.25 m
Torso tiltAbsolute difference of the Z components of unit gravity projected into the actual and reference torso frames> 0.8
Wrist or ankle heightLargest absolute world-Z difference across the left/right wrists and ankles> 0.25 m

Any one condition marks the clip as failed. Early termination stops immediately. The no-termination protocol records the first failure and continues the same controller to the exact endpoint, with no reset; recovery does not restore success. Checks run at 50 Hz after physics, plus the exact endpoint. The comparison is strictly greater-than: a value equal to the threshold does not trigger failure. A failure at the final timestamp still counts as a failed clip.

Relative to the reference

Height means tracking error, not a minimum standing height. A reference that lies down or contacts the floor is not automatically a failure. Gravity uses the unit vector (0, 0, −1); the 0.8 threshold is dimensionless, not radians or degrees.

Alignment affects metrics

XY and yaw alignment apply only to reported tracking errors. They do not change the simulated state or the failure checks. There is no additional XY, yaw, keybody-distance or contact threshold for success.

Completion and errors

Completion is the last valid sample time divided by the clip duration. Completion freezes at the first failure in both modes. Early-termination errors include the failing sample; no-termination errors include all samples through the endpoint. Invalid numerical states, inference errors and truncated smoke runs cannot produce a successful full-suite result.

Exact bodies, formula and source

Height endpoints: left_wrist_yaw_link, right_wrist_yaw_link, left_ankle_roll_link and right_ankle_roll_link.

For torso rotation R from local to world and g = (0, 0, −1), projected gravity is Rᵀg. The tilt check is |(Ractualᵀg)z − (Rreferenceᵀg)z| > 0.8. It measures agreement with the reference tilt, not heading or the full 3D angular distance.
