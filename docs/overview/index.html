A SHARED EVALUATION CORE

Fair, reproducible evaluation.

01

One kernel

Data, clocks, physics, termination and metrics are owned by a versioned core. Models bring their inference.

02

Faithful inference

Each model uses its documented inference settings within the same evaluation core. Public code and configurations support fair, reproducible comparisons.

03

Inspectable results

Bind checkpoints and source versions to a run. Recompute scores from pose traces, and make the reproduction record accessible.
