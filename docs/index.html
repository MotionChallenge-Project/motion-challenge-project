Each MuJoCo 3.17.0 batch evaluation reports success, completion and six tracking-error views. Only MuJoCo 3.17.0 batch results are published. Published evaluator ↗

Shared rules. Public code. Reproducible runs. Within each benchmark, robot and protocol, the core fixes data, physics, failures and scoring. Each entry identifies its checkpoint and inference implementation.

Rank follows the selected metric, always best first: higher success or completion, lower tracking error. The default is success, then completion. Medals mark the top three. MPBPE averages 14 body-origin distances over frames, then equally over 40 clips. Early-termination errors cover the observed prefix. No-termination errors cover the entire motion.

Success

A clip passes only if it reaches the final reference frame without any declared failure. All 40 clips use the same checkpoint.

Completion

Mean fraction of motion completed before failure. Reported alongside tracking error to describe how much of each motion was completed.

Six tracking-error views

Each rollout protocol reports XY + yaw, XY only and no alignment. These remove horizontal translation and heading, translation only, or neither. Height is retained in all six views.
