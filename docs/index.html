Type: Dense = continuous dense policies (MLP, convolutional, graph or Transformer); FSQ = finite scalar quantization; MoE = mixture of experts; FB = forward-backward latent policy; Flow = flow matching. Sources are linked from each model card.

Each MuJoCo 3.17.0 batch evaluation reports success, completion and six tracking-error views. Only MuJoCo 3.17.0 batch results are published. Published evaluator ↗

Shared rules. Public code. Reproducible runs. Within each benchmark, robot and protocol, the core fixes data, physics, failures and scoring. Each entry identifies its checkpoint and inference implementation.

Rank follows the selected metric, always best first: higher success or completion, lower tracking error. The primary metric is No termination · XY only MPBPE (lower is better). Medals mark the top three. MPBPE averages distances over the benchmark’s declared body origins and frames, then weights motions equally. Early-termination errors cover the observed prefix. No-termination errors cover the entire motion.

Success

A motion passes only if it reaches the final reference frame without any declared failure. All motions in an evaluation use the same policy and checkpoint.

Completion

Mean fraction of motion completed before failure. Reported alongside tracking error to describe how much of each motion was completed.

Six tracking-error views

Each rollout protocol reports XY + yaw, XY only and no alignment. These remove horizontal translation and heading, translation only, or neither. Height is retained in all six views.
