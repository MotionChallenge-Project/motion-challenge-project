A small adapter. A shared kernel.

MotionChallenge-your-model/
├── MotionChallenge-Core/  # pinned core submodule
├── adapter.py         # inference only
├── runtime.json       # clocks, artifacts, input contract
├── provenance.json    # source and review evidence
├── evaluate.py        # shared core entrypoint
├── pyproject.toml
└── uv.lock

The core owns datasets, physics, metrics and verification. Model repositories do not copy or override evaluation logic. Checkpoints, data and results live in local caches or external artifact storage.

Propose another dataset

Publish a manifest with immutable source revisions, file hashes, frame rate, joint order and the complete motion set. Define a distinct protocol version and benchmark identity. Preserve difficult clips, document licensing and overlap, and keep scores in their own track.
