OBSERVATION ADMISSION

Ideal proprioception

No global position feedback. A separate, frozen observation track with per-checkpoint inference evidence.

Contract: ideal-proprioceptive-no-position-v1. Noise-free inputs; physics, references, reset, failure conditions and all six tracking-error views remain unchanged. Existing privileged-state scores stay in their original track. No previous score is copied into this track.

Frozen rules ↗LAFAN40 conditions ↗Per-checkpoint records (JSON) ↓

Permitted inputs

  • Joint angles and velocities; full root orientation, including yaw.
  • Ideal linear and angular velocity at the root body origin, expressed in world axes.
  • Gravity projection and local forward kinematics derived from those inputs and fixed robot geometry.
  • Reference motion, including world coordinates, velocities and the declared history/future window.
  • Previous actions and author-native proprioceptive or recurrent history.

Excluded information

Actual global root XYZ, including height; actual global body positions; contact flags, forces and impulses; actual-position tracking errors; explicit velocity integration into displacement, odometry and root-position estimators. These restrictions also apply to initialization, reset, history caches, reference alignment and preprocessing.

Special handling

Local FK or a synthetic fixed origin must preserve the released inference numerically, or implement a documented author deployment path for the exact checkpoint. Reference-only anchoring must be disclosed. A required actor input cannot simply be zeroed to obtain admission. Training critic or reward privilege does not determine deployment eligibility.

The Core removes forbidden fields before reset and action messages reach the adapter. Source audit, input-dependency tests, author inference comparison and a fresh complete verified evaluation are separate checks. Native recurrent state is permitted; this rule does not prove that a network never implicitly infers displacement. Ideal inputs do not establish real-world sensor feasibility.
